# Play Station Sulim — стартовый сайт

## Что уже работает
- Адаптивная одностраничная витрина для телефона и компьютера.
- Темный премиальный игровой стиль, анимации и плавное появление блоков.
- Список игр и тарифы.
- Кнопка фоновой музыки; трек извлечён из присланного видео, с плавным затуханием последних 3 секунд и плавным входом в начале.
- Калькулятор аренды с акцией «третий день бесплатно» при сумме аренды от 1 800 ₽ (доставка не учитывается).
- Форма заявки собирает SMS на номер владельца 8 938 023-50-66.

## Важно: что пока НЕ подключено
Это первый готовый фронтенд-этап, а не полностью запущенная система бронирования.
- Форма открывает SMS и сама не записывает заказ в базу.
- Нет проверки свободных дат и защиты от двойного бронирования.
- Нет входа в админ-панель и управления заказами.
- Перевод на Т-Банк не проверяется автоматически; оплату нужно проверять вручную.
- Фотографии реальных консолей и лицензированные обложки игр пока не добавлены: графика карточек сделана оригинальной типографикой.

## Публикация на Netlify
Для предварительного просмотра можно загрузить содержимое этой папки в GitHub-репозиторий `play-station-sulim` и подключить его к Netlify. Build command оставить пустой, Publish directory — `.`.

Не считайте бронирование подтвержденным, пока владелец не ответил и не подтвердил наличие дат.
